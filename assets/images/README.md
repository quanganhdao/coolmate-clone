# Ảnh cần bổ sung

Bỏ file vào đúng thư mục này với đúng tên dưới đây là trang tự hiển thị (chưa có ảnh thì trang hiện khung xám kèm tên file).

| File | Vị trí | Kích thước gợi ý |
|---|---|---|
| `logo.svg` | Logo header (có file này thì logo chữ tạm sẽ ẩn đi) | 72×44 |
| `story-1.jpg` … `story-7.jpg` | Hàng ảnh tròn danh mục (chỉ hiện trên mobile) | 128×128 |
| `hero-1.jpg` … `hero-5.jpg` | Slider hero bản desktop | 1920×788 |
| `hero-1-mobile.jpg` … `hero-5-mobile.jpg` | Slider hero bản mobile | 750×1090 |
| `banner-nam.jpg`, `banner-nu.jpg` | Banner Đồ nam / Đồ nữ | 1440×896 |
| `banner-running.jpg`, `banner-pickleball.jpg` | Banner Running / Pickleball | 1440×896 |
| `care-1.jpg` … `care-8.jpg` | Dải ảnh chạy ngang Care & Share | 1200×1100 |
| `community.jpg` | Ảnh lớn Cộng đồng Coolmate | 1200×1300 |
| `event.jpg` | Ảnh thẻ sự kiện | 600×800 |
| `badge-ncsc.png`, `badge-dmca.png`, `badge-iso.png`, `badge-bct.png` | Huy hiệu ở footer | cao 36px |

**Ảnh sản phẩm và bộ sưu tập**: mở `js/data.js` rồi điền đường dẫn vào trường `img` của từng mục, ví dụ `img: "assets/images/products/bondtech.jpg"`.

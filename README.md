# Coolmate Homepage Clone (Demo)

Bản dựng lại giao diện trang chủ Coolmate bằng HTML/CSS/JS thuần, **phục vụ mục đích học tập**.
Trang này không phải website chính thức của Coolmate và không liên kết với Coolmate. Thông tin liên hệ trong trang là dữ liệu mẫu.

## Chạy local

```bash
python -m http.server 5173
```
